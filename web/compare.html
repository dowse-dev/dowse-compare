How is this scored?
  1. Same query, 10 results each. Every API gets your query at the same time and returns its top 10, with its default settings.
  2. One blind pool. All results go into one list: copies of the same page are merged, the order is shuffled and the API names are removed.
  3. An AI judge grades every result 0–100 for how well it answers your query: Jev, TypeSafe's System One model on OpenRouter, with a prompt written for judging and published in the code. Dowse also uses Jev, with a different prompt, to rank its own results, which is why the judge never sees which API returned what. Spam and clickbait are marked down, and the judge knows today's date. Relevant is 60 or more, partly 30–59, off-topic under 30.
  4. Each API's score, 0–100 (nDCG@10): its 10 results in its own order, compared with the best 10 that any API found. Higher positions count more (#1 about 3.5 times as much as #10), and missing a great page another API found costs points. A perfect list scores 100.
  5. Ties. The judge varies a little between runs, so a lead of less than 2 points is a tie and nobody gets the badge.
  6. Time and price. Time is measured from our server in the US. Price is each API's published price per query at its entry paid tier.
  7. Click a result to see whether each API can actually read that page: it fetches the page with every extract API and the judge checks each text against your search.
  8. Check it yourself. Every run has a JSON file with all results, every grade and the exact request we sent the judge. How it works

  • Your query goes to all seven APIs at the same time through their public APIs, each asked for 10 results with its default settings: Dowse basic, Exa auto, Tavily basic, the Perplexity Search API, Context.dev web search, Parallel (its default, advanced) and Keenable (its default, pro). Dowse also runs its advanced mode, which plans extra searches first and costs twice its basic price. Every API gets only your query; Parallel's docs suggest also writing a goal and 2-3 keyword queries, which no API here is given.
  • Every unique result from all of them goes into one pool. Duplicates are merged, the order is shuffled and the API names are removed.
  • The judge grades each result for how well it answers the query and marks spam or clickbait down.

The score

Each API gets an nDCG@10 score from 0 to 100: its own top 10, in its own order, compared with the best 10 results any of them found. An API loses points for weak results near the top and for missing strong results that another API found. Times are measured from our server in the US.

Prices are each company's published list price for one query with these settings, at its entry paid tier: Dowse at the $10 pack, Exa's own reported cost for the call, Tavily and Perplexity pay as you go, Context.dev on its $20 Developer plan, Parallel and Keenable pay as you go. Bigger plans cost less per query for all of them.

The judge varies a little between runs, so a lead of less than 2 points is called a tie. A query run again within a day shows the earlier run. Every run stays in the list on the left, so anyone can check it.

How it works

  • The URL goes to all seven extract APIs at the same time, each told to fetch the page live where it allows: Dowse basic extract, Exa contents, Tavily basic extract, the Perplexity Context API, Context.dev scrape, Parallel Extract and Keenable fetch. Tavily has no setting for a live fetch, so it may answer from a stored copy.
  • An AI judge (Jev) reads every text that came back, numbered in random order and without the API names, and answers yes or no: is this the page's real content, or a login wall, bot check, cookie notice or error page?
  • The page shows the first part of each text only.

Badges and prices

An API passes when it got the page and the text is its real content. Passing does not mean complete: compare the lengths. Times are measured from our server in the US.

Prices are list prices for one page at the entry paid tier: Dowse at the $10 pack, Exa and Perplexity as they report them, Tavily pay as you go, Context.dev on its $20 Developer plan. A page compared again within 6 hours shows the earlier run.
